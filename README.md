# VisionAid-Smart-Assistant
An ESP32-based AI smart assistant cane featuring real-time obstacle detection and automated wheel braking.

VisionAid is a modern assistive technology that was created to help those who are visually impaired improve 
their mobility, safety and independence. Visually impaired people can have trouble navigating new environments 
every day. Although the traditional use of a white cane to assist with mobility is commonplace, it is limited to 
detecting the presence of obstacles close by. Therefore, the visually impaired need a more sophisticated and 
reliable solution. 
 
The purpose of this project was to develop an intelligent assistive system that incorporates both modern 
technology (such as embedded system, Internet of Things (IoT) and sensing techniques) into one single 
functioning unit. The heart of this system consists of an ESP32 microcontroller (used as the main control unit for 
coordinating the operation of all components of the system), Ultrasonic sensors that will measure distance in real
time (to indicate the presence of any obstacles that may be present within the operating environment), and audio 
alerts to inform the user of obstacles in their path to avoid collision with them. In addition, a GPS enabling module 
is included to allow for the system to track the user's current position (to assist with navigation) and a GSM 
module to send an emergency alert message including user's current location to pre-defined contacts if needed. 
 
This project implements a simple, economical and user-friendly Electric Eye system to assist blind people with 
greater confidence and security. Throughout the implementation of VisionAid there was evidence to show that 
users felt more confident and safe when using the device. Overall, this project has been successful in illustrating 
that by using an integration of multiple technologies, a practical and efficient solution can be achieved for real
world use.
